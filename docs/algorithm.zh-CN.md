## 1. 问题：周期结构的衍射效率

一个在 x、y 方向周期排列的薄膜结构（周期 Λx、Λy，厚度 h），层内介电常数 ε(x, y) 不随 z 变化。平面波从入射侧的半无限介质（折射率 n_in）射入，从折射率 n_out 的介质射出。
周期性把透射光分成离散的**衍射级次** (m, n)，每个级次带走一份功率 η_{m,n}。
逆设计问的是：哪种二值图案 ε(x, y)（"有材料 / 没材料"）能把尽可能多的功率送进指定的一个级次？

## 2. RCWA（傅里叶模态法，FMM）怎么解

### 2.1 展开
把周期函数 ε(x, y) 与场展开成傅里叶级数，只保留 |m| ≤ Mx、|n| ≤ My 的 **N = (2Mx+1)(2My+1)** 项。
截断是 RCWA 唯一的近似。各级次的横向波矢是

k_{x,m} = k_{x,0} + m·2π/Λx，k_{y,n} = k_{y,0} + n·2π/Λy。

周期越大，倒格矢间距 2π/Λ 越小，覆盖同样一段物理 k 空间需要的级次越多——**大周期问题需要大截断阶**。
一个可用的经验下界是 M ≈ n_max·Λ/λ（覆盖膜内所有传播方向）；收敛通常还要再乘 2。

### 2.2 卷积矩阵
把 ε(x, y) 的傅里叶系数排成 N × N 的 Toeplitz 型**卷积矩阵** ⟦ε⟧，元素为 ε_{m−m', n−n'}。构造它需要 ε 到 2Mx、2My 的傅里叶系数，
所以像素网格必须满足 nx ≥ 4Mx+1、ny ≥ 4My+1（否则系数混叠）。工作台面板里的约束就来自这里。

### 2.3 每层一个本征问题
层内 Maxwell 方程化为横向电场傅里叶系数的二阶常微分方程：

d²E/dz² = −k₀² (P Q) E，

P、Q 是由 ⟦ε⟧、⟦ε⟧⁻¹ 与对角波矢矩阵拼出的 2N × 2N 矩阵。**PQ 的本征分解** PQ = W Λ W⁻¹ 给出模式 W 与传播常数 q = √Λ；
磁场模式 V = P⁻¹ W diag(q)。这一步（`torch.linalg.eig`）是整个求解的主要开销。

### 2.4 S 矩阵级联
在每个界面上，横向 E、H 连续给出一个 4N × 4N 线性方程组，其解是该界面的散射矩阵（S11、S12、S21、S22）；
层内传播只是对角相位因子；Redheffer 星积把各块级联成全局 S 矩阵。与传输矩阵法不同，S 矩阵不受倏逝波指数增长导致的溢出影响。

### 2.5 输出
全局 S21 作用在入射矢量上给出每个级次的复透射振幅 t_{m,n}；功率 η_{m,n} 是 Poynting 通量 (E × H*) 除以入射功率，只有传播级次（实 k_z）非零。
能量守恒残差 |R + T − 1| 是最基本的自检。

**代码**：`trustworthy_fmm/fourier/convolution.py`（卷积矩阵）、`solvers/vector_2d.py`（P、Q、本征问题、级联、功率）、
`scattering/smatrix.py`（界面 S 矩阵、星积）、`solvers/eigendecomposition.py`。

## 3. "可微"是什么意思，GPU 怎么用

### 3.1 自动微分
整个前向求解都用 PyTorch 张量运算写成——FFT、矩阵乘、线性求解、本征分解都有反向传播规则。
所以 dη/dε(x, y)（效率对每个像素介电常数的导数）一次反传就得到，代价约等于一次前向。
没有这个梯度，几万像素的设计问题只能靠随机搜索。

本征分解的反传含 1/(λ_i − λ_j) 型放大，两个本征值近简并时会放大。单精度下它偶尔给出**有限但错误**的梯度（范数大 10–500 倍、方向几乎与真梯度正交）；同一点在双精度下梯度正确，
本征间隙的大小*不能*预测它在哪里发生，其它求解器用的 Lorentzian 加宽也修不了它（ε ≥ 1e−6 时反而把健康梯度偏转 20–30°）。因此工作台保留精确反传，用运行时守卫（§5.2）捕捉这类事件。
库里仍带可选的 Lorentzian 稳定化，默认关闭。

### 3.2 设计映射（把"像素"变成"可制造图案"）
直接优化像素得到的是不可制造的像素噪声。工作台用标准的三段映射：

潜变量 ρ ∈ [0,1]^{ny×nx} → 对称化（可选）→ 周期高斯滤波（半径 r_f）→ tanh 投影（锐度 β）→ 连续密度 ρ̃ ∈ [0,1]
→ ε = ε_bg + (ε_feat − ε_bg)·ρ̃。

交付图案不用 ρ̃，而用**硬阈值**：滤波后 ≥ 0.5 的像素为材料——这才是二值的、可制造的图案。
滤波半径决定最小特征尺寸；β 从小到大的连续化让优化先在平滑景观里走，再逐渐逼近二值。

要点：优化器看到的 η(ρ̃) 是**松弛值**（灰度像素相当于不可制造的中间介电常数，多出的自由度使数字系统性偏高）；
交付图案的效率必须用硬二值重算。工作台把两者分开画（细线 vs ◆），从不报松弛值。

**代码**：`trustworthy_fmm/fabrication/process.py`（滤波、投影），`workbench/app.py` 里的 `app_filtered / app_projected / app_hard_binary`。

### 3.3 GPU、精度与本征分解在哪里算
- 所有张量在 CUDA 上以 `complex64`（单精度复数）存放。单精度让矩阵代数快数倍、显存减半；对效率这种 O(1) 量，与双精度的差在 1e−4 量级。高精度核对用 `CPU / complex128`（并记住 §3.1：单精度的*梯度*在孤立点上可能是错的，由守卫处理）。
- **本征分解本身默认在 CPU 上算**（`TFMM_EIG_DEVICE=cpu`）：在参考环境（torch 1.13 / CUDA 11.7 / Windows）上 CUDA 本征求解器每次调用都泄漏主机内存（约矩阵大小的 0.4 倍，800 步下降约 12 GB），
  长跑以内存不足告终。矩阵移到主机做 `torch.linalg.eig`，本征对再移回；autograd 追踪两次拷贝，梯度不变。代价是本征分解墙钟约 +30%，此时 BLAS 线程数（`FMM_THREADS`，默认 3）直接影响墙钟。
  若你的 torch 不泄漏，设 `TFMM_EIG_DEVICE=native` 在 GPU 上分解。
- 显存：矩阵是 2N × 2N，每个 complex64 元素 8 字节；一次求解同时保有几十个这样的矩阵（模式、S 块、4N×4N 界面系统的临时量），反传还要保存差不多同样多的中间量。**峰值显存 ∝ (2N)²**。用混阶梯度（§5.2）时显存峰值在闸门阶的反传，不在下降阶。
- 两个省显存的开关（都不改变数学）：
  - **"内存高效路径"**：P、Q、V 用向量缩放而不是与对角矩阵稠密相乘来装配；界面系统的右端从系统矩阵切片而不是重建；层内传播的星积退化为逐元素相位缩放；重复使用的左端矩阵只做一次 LU。前向峰值与反传保存量都明显下降。
  - **"save_on_cpu"**：反传要保存的张量搬到（锁页）主机内存，峰值显存回落到前向峰值，代价 +10–20% 时间。自动模式在最大梯度阶的 2N ≥ 3000 时打开。
- 时间：前向以本征分解为主（真实结构的矩阵比随机矩阵慢，QR 迭代收敛更慢），其次是 4N×4N 界面求解；反传主要是矩阵乘，通常比前向便宜。一步优化 ≈ 1.2–1.5 次前向。

**代码**：`solvers/vector_2d.py` 顶部的 `MEMORY_EFFICIENT / CHECKPOINT_SMATRIX / GAP_ONLY_DIAGNOSTICS` 开关及注释；`solvers/eigendecomposition.py` 的 `EIG_DEVICE`；
`scattering/smatrix.py` 的 `propagation_star / redheffer_star_fused / interface_smatrix_direct`。

## 4. 三层截断阶：下降、闸门、认证

同一图案在不同截断阶给出不同的 η，阶越高越接近真值（材料边界不连续，傅里叶级数收敛慢）。
这里有个陷阱：在低阶上做决定的优化器会挑出**恰好在低阶被高估**的结构（选择偏差，optimizer's curse），交付图案在高阶一算就塌。工作台用三层阶把"算梯度"、"做选择"、"报数字"分开：

| 层 | 用途 | 调用次数 | 要求 |
|---|---|---|---|
| 下降阶 | 大多数步的值 + 梯度 | 步数 × 票数（几百到几千） | 便宜；梯度方向对即可；**它的值不进任何决定** |
| 闸门阶 | 票里每第 4 个梯度（§5.2）；给每个候选二值打分；决定选哪张票 / 链候选是否接受 | ≈ 步数/4 次梯度 + 每个候选一次前向 | ≥ 2 × 下降阶 |
| 认证阶梯 | 交付图案的收敛阶梯：**一档**是每张票都读的值（统计层），**顶档**是报告值 | 每档一次 | 越高越好；高目标级次时顶档可能仍未收敛（m = 3、4 时相邻档差 +0.004…+0.02），所以两个数都报 |

测量对三层阶的结论（实验 S5、S6、S8）：闸门阶买到的是**诚实的报数**而不是更好的结构（2× 已够；在下降阶选票会把交付值高报 0.1–0.3）；
下降阶必须随目标级次缩放，在起点和每次再下降都是（低一档封顶可达效率，高一档每步贵 7–10 倍而单票无增益）；
下降阶的截断误差随投影锐度开关式出现（β ≤ 16 时 |误差| ≤ 0.02，β ≈ 128–1000 时饱和于二值间隙）。

### 4.1 阶规则（**"按目标自动填阶"**）
基数是膜内传播截止 M₀ = n_feat·Λx/λ：目标级次 m ≤ 2 时下降 ≈ M₀、闸门 ≈ 2M₀；m ≥ 3 时下降 ≈ (m+2)/3·M₀、闸门 ≈ (m+5)/3·M₀；
认证在闸门之上再加两档；My 按周期比缩放。目标级次越高、图案越细（滤波半径越小），需要的阶越高。
规则被网格约束截断时，界面显示所需的 nx/ny——先加密网格再相信数字。

**代码**：`workbench/app.py` 的 `order_rule`、`certify_ladder`、`gate_eval`；`workbench/protocol.py` 的 `rise_ladder`。

## 5. 优化协议：守卫混阶票、闸门选票、认证、可选的修复链

### 5.1 为什么单纯下降不够
像素化拓扑逆设计高度非凸：梯度只指出局部方向，落入哪个局部最优由随机初值决定。经典对策是**多起点**（每个种子一条下降，取最好），工作台保留这个结构：一个种子 = 一张**票**。

单纯下降里有两件事会出错，下面的协议就是围绕它们设计的：

1. **优化器会爬截断误差。** 投影一旦变锐（β ≳ 16…128），便宜的下降阶就把当前设计的目标高估恰好一个硬二值截断间隙（参考问题上 0.05–0.2；把运行末尾的连续值与认证值相比是 +0.1…+0.4）。
   优化器把这个误差当物理来追：连续值一路上升，同一条轨迹的认证值停滞或坍缩（相邻检查点之间 0.1–0.5 的"断崖"）。已发表的单阶工作流报的就是那个虚高的数。
2. **单精度梯度偶尔是错的**（§3.1）：在孤立的 β 值上出现范数大 10–500 倍、方向偏斜的有限梯度（约每 100 次评估 1–2 次）。Adam 的逐像素归一把它变成一步满步长的错向更新，动量再带十来步；
   参考池里一次这样的闸门阶事件先于一次从 0.89 到 0.14 的坍缩。

### 5.2 一张票
| 项 | 值 | 为什么 |
|---|---|---|
| 排程 | 219 步 Adam（lr₀ = 0.02，余弦到 0），β(t) = 2·(2000/2)^{t/219}：几何"README 坡" | β 终点是排程的主因子（对 β → 64 认证值 +0.1–0.25）；219 步以 60% 的墙钟达到 800 步的中位，同样的钱能多抽票 |
| 混阶梯度 | 从首个 β ≥ 16 的步起，每第 4 个梯度在**闸门阶**算（同一 Adam 状态），其余步用下降阶 | 爬截断误差的直接解药：运行中的截断间隙从 0.14–0.18 降到 0.02–0.03，认证值 +0.09（m = 1、2）；增益随单阶间隙的大小变化（m = 3 / 4 为 +0.03 / +0.01）。β < 16 时下降阶梯度已与高阶一致，更早混阶只花钱 |
| 探针 | 每个闸门阶步再算一次同一潜变量的下降阶梯度（约占下降墙钟 7%） | 提供进度图里的连续值、两阶梯度的余弦（D1/D2 变体用）、以及闸门阶梯度被拒时的后备更新 |
| 范数守卫 | 每次梯度（下降、闸门、探针）：若 ‖g‖ > 最近 8 次同阶范数中位的 3 倍（预热 4 次、β ≥ 8），在 β(1 + 1%) 重算；原梯度若在此变化下**稳定**（余弦 ≥ 0.9 且范数比在 [0.5, 2]，即自然增长）则保留，否则用重算（伪像）。raise / 非有限梯度：±1%、±3% 阶梯，再一次 CPU complex128 梯度（每票最多 6 次）；闸门阶上改走一步下降阶 | 在参考池上校准：被替换的梯度范数比 ×16–289；真阳性每 100 次评估 0.5–2 次；守卫把池里的断崖清零（0/6 对 1/6），价格不变 |
| 检查点 | 每票 30 个（每 12 步加一组早疏晚密）：当前潜变量硬阈值化后在闸门阶读数（并在下降阶读一次，得截断间隙曲线） | 运行中的闸门读数接住断崖与坍缩：最好的检查点常常不是最后一步 |
| 交付 | **闸门读数最好的检查点**（不是末场，更不是连续值）；末场另存 | 连续值系统性偏高（+0.1…+0.4）；末场可能就是坍缩的那个 |
| 价格 | 第二个参考问题 m = 4 每票约 13 min（下降墙钟的 ≈ 70% 花在闸门阶梯度上），m = 3 约 7 min，m ≤ 2 约 1 min（RTX 3060） | 实测；面板提示按你的设置数闸门阶梯度与检查点读数 |

### 5.3 选票与认证
- 每个种子抽一张票（默认三张）；**按交付检查点的闸门读数选**（诚实的值；按连续值选会选中虚高最多的那张，损失 0.01–0.05）。
- 每张票都在认证阶梯的一档读一次；胜者在整个阶梯上认证。结果汇总报 **闸门、一档、顶档、一档 − 顶档** 与**闸门乐观量** = 闸门 − 一档。
  乐观量超过约 0.03 说明闸门阶仍在美化设计；一档 − 顶档超过约 0.01 说明顶档未收敛——先把阶梯（和网格）往上加再引用数字。
- 乐观量小、认证值沿阶梯还在上升，是健康交付的样子；最好检查点很早（步 < 100）而末场坍缩的交付是**修复候选**（§5.4）。

### 5.4 修复链（可选，默认关）
对交付票做盆地跳跃：每跳 = 现任潜变量 + α × 0.08 × 单位方差滤波噪声（α 轮转 0.1 / 0.25 / 0.5），在**固定 β** 下再下降 30 步 Adam（k = 4 混阶自第 0 步起，新 Adam，余弦 lr，同样的守卫，守卫窗口每跳重置），
硬阈值，闸门阶一次前向，**单调接受**（只有更高的闸门读数才替换现任），每次接受读一档（追踪假接受）。默认 15 跳，连续 12 次拒绝即停；价格约 2.4 张票。

它是*修弱票*的工具，不是提升好票的工具。参考问题上 93 条链给出的是：
- 在三选一的最好票上（认证 0.73–0.91），26 条里 24 条零接受；
- 早见顶或坍缩（最好检查点在第 ~100 步之前）且闸门乐观量小（< 0.03）的票，11 张修好 10 张（+0.2…+0.4）；乐观量 ≥ 0.03 的 17 张修好 5 张；强父本 55 条里 1 条；
- 再下降 β 决定跳能不能工作：β ≤ 200 修好 15/28，β ≥ 500 只有 2/8；同父本、同噪声下，β = 64 对票的交付 β（β* ≈ 10³）从未输过——4 胜 6 平。所以**默认 β = 64**；`max(β*, 64)` 作为选项保留。

面板给三种起链方式：**总是**（认证后直接起链）、**数值判据**（交付一档低于你填的下限*且*闸门乐观量低于 0.05 才起链）、**手动**（先跑票，看结果汇总，再在结果汇总或历史运行里对保存的交付起链）。
链跑过后，交付图案是链的现任（在闸门上永远不低于父本）。

### 5.5 等墙钟对照
链跑过且勾选了对照时，把链的墙钟花在额外的票上（只有预计能在预算内完成才开新票），把"原票 + 额外票按闸门选一"与链现任在一档上比较。这是关于链的诚实问题——"同样的钱换成票会不会更多"——在强父本上答案通常是会。

### 5.6 可选变体（开关，默认关）
- **D1 自适应节奏**：混阶间隔 k ∈ {2, 4, 8} 跟随探针与闸门阶梯度的余弦（连续两次探针 > 0.95 → k 加倍；< 0.85 → k 减半），闸门阶步总数以 k = 4 会花的数为上限。观测：早期 k = 8，后期 k = 2。
- **D2 在线升档**（需 D1）：在同一"两次 < 0.85"事件上下降阶同时向闸门阶升一档（每档 Mx + 4），只升不降；到第 ~200 步每张票都在闸门阶下降。价格约 +30%。
- 状态：各 6 张票上它们的中位与 E[三取最大] 比默认高 0.02–0.03（认证 0.899 / 0.907 对 0.880），各有 1 张断崖——按数据前写好的采纳规则（两项不低*且*断崖更少或更便宜）属于"有希望、未确认"。

### 5.7 试过但没用的东西
| 不做 | 反证 |
|---|---|
| 本征间隙守卫 | 错误梯度出现在普通的间隙上；5% 的健康步间隙更小 |
| 方向守卫（对上一梯度的余弦） | 移动的潜变量上相邻梯度余弦中位 0.88、25% 分位 0.37 |
| 闸门阶梯度与探针不一致就弃用 | 坡的后段两阶真实地反向（余弦 −0.6…−0.9）：那正是被爬的截断误差 |
| Lorentzian 本征反传加宽 | 不改变错误梯度；偏转健康梯度 |
| 闸门阶步用独立的 Adam 状态 | 带偏差修正的首步是满步长符号步 |
| 重分配坡密度（β 16–128 多放步） | 不优于父配置；多两张早见顶票 |
| 坡终点 β = 64，或在票的交付 β 上再下降 | 票要 β → 2000，链要低 β；链只判硬二值，两者不矛盾 |
| 报连续值，或用 min{标称, CD±} 作链的接受 | 虚高 +0.1…+0.4；接受用标称闸门读数 |

### 5.8 换问题怎么定参数
1. 阶：**按目标自动填阶**；规则被截断先加密网格。
2. 价格阶梯：选阶梯前先给每个阶计一次梯度时间（第一次运行后汇总里的每票墙钟就是）。
3. 坡：219 步、β 2 → 2000 是两个参考问题的校准值；不要先动它们。
4. 守卫：3× / 窗 8 / 预热 4 / β ≥ 8 / 稳定性 0.9 & [0.5, 2] 在 GPU complex64 上校准；换精度或求解器后，先不勾守卫跑一次，看汇总里的触发计数（1–3% 的"本应触发"是校准过的区间）。
5. 修复：对早见顶或坍缩、乐观量小的票手动起链；β = 64。

### 5.9 旧版链式协议
以"旧版链式协议"保留，用于与 2026-09 之前出货的方法对照：几条起点下降（β 1 → 64，最优闸门检查点）→ 40 跳盆地跳跃，每跳 30 步单阶再下降 β = 64 → 单调闸门接受 → 认证，外加等墙钟重启彩票。它的票是旧的 β → 64 票且没有守卫；只用来复现旧运行。

**代码**：`workbench/descent.py` 的 `GradPolicy`、`TicketDescent`、`repair_chain`；`workbench/app.py` 的 `run_ticket`、`guarded_mixed_protocol`、`run_repair`、`control_arm_gm`、`run_optimize`；
`workbench/protocol.py` 的参数块 `DESCENT / GUARDS / REPAIR / CADENCE / RISE`、`beta_geometric`、`o_ckpts`、`rise_ladder`；旧版：`e10_descent`、`chain_protocol`、`restart_arm`。

## 6. 鲁棒性：把加工偏差算进去

### 6.1 为什么
优化器会利用求解器允许而工艺不允许的自由度：亚分辨率细线、恰好卡在阈值上的边界像素。这类结构在标称几何上效率很高，边界一动就塌。

### 6.2 怎么模拟加工缺陷
没有物理光刻仿真；代之以对交付二值图案做**几何扰动**。基础是周期**有向距离场** d(p)：每个像素中心到最近的另一类像素中心的距离，材料内为正（3×3 平铺保证周期性；单位 nm）。

| 缺陷 | 算子 | 含义 |
|---|---|---|
| CD 偏置 | 生长 b：保留 {p : d(p) ≥ −b}；收缩 b：保留 {p : d(p) > b} | 所有边界外扩（b>0）或内缩（b<0）b nm；模拟全局剂量 / 刻蚀偏差 |
| 开 / 闭运算 | 半径 r 圆盘的形态学开 / 闭 | 抹掉细于 2r 的线 / 填掉窄于 2r 的缝；模拟分辨率极限 |
| 线边粗糙 | d(p) ≥ −(b + σ·g(p))，g 为相关高斯场 | 边界的随机起伏（确定性样本，不主张最坏情况） |
| 侧壁倾斜 | 上下不同偏置，多层堆叠 | 非垂直刻蚀 |

注意像素量化：小于一个像素的偏置不改变任何像素，生长与收缩对称（一个像素的偏置让每条边在任一方向移动一个像素）。

### 6.3 鲁棒性检验与鲁棒接受
- **审计**（留出）：交付后把扰动图案在认证阶重算，报最坏效率与"最坏 / 标称"比。审计场景**从不**参与优化，所以得到的是对未见扰动的泛化而不是对审计的过拟合。工作台默认审计 CD ±20 nm。
- **鲁棒接受判据**（仅旧版链式协议）：链的接受分数改为 min{标称, CD−b, CD+b}（都在闸门阶算），每跳多两次前向。

**代码**：`trustworthy_fmm/fabrication/process.py`（有向距离、形态学、相关随机场、软代理），`workbench/protocol.py` 的 `cd_bias_mask`，`workbench/app.py` 的 `gate_score`。

## 7. 引擎交叉验证

- **TORCWA**（开源可微 RCWA 求解器）：同一图案、同一截断阶，两个引擎的 η 一致到 1e−5 量级——这验证的是实现，不是截断收敛。
  已发表的 TORCWA 工作流（800 步、单一截断阶、报连续值）是 §5 协议的对照目标：等墙钟下 §5.2 的票在参考问题上交付更高的认证值，而单阶工作流报的数虚高 +0.1…+0.4。
- **Ansys Lumerical RCWA**：先把二值图案精确转换成像素边界多边形（反向光栅化必须逐位复原图案），交给 Lumerical 自带的 RCWA 求解器，在其 k 向量阶梯上求解，与本引擎最高阶的值比较。只支持 x 偏振正入射（P 源约定）。

**代码**：`workbench/app.py` 的 `torcwa_block / lumerical_block`，`workbench/polygons.py`。

## 8. 术语表

| 术语 | 一句话 |
|---|---|
| 截断阶 (Mx, My) | 每个方向保留的傅里叶级次半宽；矩阵维度 2N，N = (2Mx+1)(2My+1) |
| 松弛值 | 连续（灰度）设计的效率，优化器的目标；不可制造、系统性偏高 |
| 二值@闸门 | 硬阈值后可制造图案在闸门阶的效率；所有选择的依据 |
| 认证阶梯 / 一档 / 报告值 | 交付图案在递增截断阶上的效率序列 / 闸门之上的第一档（每张票都在此读数）/ 最高档的值 |
| 闸门乐观量 | 同一图案的闸门读数减一档值；闸门阶还在多美化设计多少 |
| 漂移 | 闸门值到报告值的变化；强负漂移说明设计被低阶"美化"了 |
| 票 | 一个种子的一条守卫混阶下降，交付其最优闸门检查点 |
| 混阶梯度 | 票里每第 k 个梯度在闸门阶算，同一 Adam 状态；爬截断误差的解药 |
| 探针 | 与每个闸门阶梯度同时算的下降阶梯度（同一潜变量） |
| 范数守卫 / 真阳性 | 梯度范数超过近期中位 3 倍时的触发 / 触发后在 1% 的 β 变化下不稳定而被替换的梯度 |
| 断崖 | 最优闸门检查点减末场的闸门读数；断崖大说明运行在最好点之后坍缩了 |
| β* | 交付检查点所在步的 β（可选的 `max(β*, 64)` 再下降规则用它） |
| 修复链 | 对交付票在固定低 β 上的盆地跳跃；修弱票的工具，不是提升工具 |
| 等墙钟对照 | 把链的墙钟花在额外票上的对照臂 |
| 留出审计 | 交付后在优化中从未用过的扰动场景上重算 |
